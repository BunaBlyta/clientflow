## 19:00 – 22:00 · Deploy

Yours, not an agent's — it involves credentials. Work through it in this order.

**Before you deploy:**

- [ ] Change the build script in `package.json` to `"build": "prisma generate && next build"`.
      Vercel caches `node_modules`, so Prisma's postinstall may not regenerate the
      client. This is the most common first-deploy failure on this stack.
- [ ] Note that **local and Vercel share the same Neon database.** `npx prisma db seed`
      resets invoice statuses for both. Do not reseed during or just before a demo.

**Environment variables to set in Vercel:**

- [ ] `DATABASE_URL` — the **pooled** Neon connection string (the one with
      `-pooler`), not the direct one. Serverless functions exhaust direct
      connections.
- [ ] `SESSION_SECRET` — the app throws in production without it, by design, from
      the 11 Aug hardening. This one will fail loudly, which is what you want.
- [ ] `APP_URL` — your Vercel URL. `app/api/stripe/checkout/route.ts` falls back to
      `request.nextUrl.origin`, which behind a proxy can produce the wrong redirect.
- [ ] `RESEND_API_KEY`
- [ ] `STRIPE_SECRET_KEY`
- [ ] `STRIPE_WEBHOOK_SECRET` — **a new one.** Register a webhook endpoint in the
      Stripe dashboard pointing at `https://<your-app>/api/stripe/webhook` and use
      the `whsec_` it gives you. Your local `stripe listen` secret will not work,
      and a wrong secret shows up as webhooks returning 400.

**The non-obvious one:** `middleware.ts` gates CORS to `NODE_ENV === "development"`
and localhost origins only. A deployed API will therefore **reject `expo start --web`**
from any other origin. Native builds have no CORS so a real device would be fine —
but the app has never run on one. So: **demo the mobile app against your local API**,
and leave `EXPO_PUBLIC_API_URL` pointed at `localhost:3000`. Deploy the web app;
do not repoint mobile at it.

**When it is up:** log in as staff, open one dashboard page, and make one Stripe
test payment against the deployed webhook. That is enough to prove it. Do not go
