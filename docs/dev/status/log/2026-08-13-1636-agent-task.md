# Mobile theme and localization

## What changed

- Added a user-selectable System/Light/Dark appearance preference and persisted
  explicit choices locally for native and Expo web builds.
- Migrated mobile screens and shared components to centralized light/dark color
  tokens, including auth, project, note, invoice, checkout, notification,
  account, loading, empty, and error states.
- Added English, Albanian, and German UI translations with English fallback.
  User-generated content and API notification messages are still displayed as
  received.
- Added theme and language controls to the Account screen.
