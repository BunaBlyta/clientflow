# API lane — status action endpoints

Date: 2026-08-11

Implemented exactly the two requested write endpoints: staff-only invoice status updates and staff-only project status updates. Invoice transitions use the existing tested state machine, reject manual `PAID` and `REFUNDED`, and return the existing serialized invoice shape. Project updates return the existing flat project shape and atomically add a system note using the established `Status changed from … to …` wording.

Added endpoint tests for staff/client authorization, valid and invalid statuses, illegal invoice transitions, the `SENT → PAID` rejection, serialized responses, and project audit notes. `npm run verify` passed typecheck, lint, and 16 tests; its Turbopack build hit the known sandbox process/port restriction. `npx next build --webpack` passed as the fallback. No migration or install was run.
