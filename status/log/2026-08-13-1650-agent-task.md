# Nested project UI cleanup

## What changed

- Removed the in-content back controls from project detail, notes, invoices,
  invoice detail, and checkout. The existing top navigation bar remains the
  back affordance.
- Removed status pills and the notifications tab badge. Statuses are now plain
  semantic text, and notification read/mark-read behavior is unchanged.
- Reworked notes into separated authored rows with deliberate spacing and
  dividers. Invoice rows retain clean dividers and a quieter status hierarchy.
