# Mobile: app-wide spacing consistency pass

- User asked for a pass across the whole app to catch spacing/card/text inconsistencies while keeping the current look intact.
- Audited every screen and shared list-row component (`app/(app)/**`, `app/(auth)/**`, `components/**`) for: off-4px-grid magic numbers, duplicated/bespoke versions of shared components with drifted spacing, and the same shared component rendering with different effective spacing in different places.
- Fixed:
  - `app/(app)/settings/help-support.tsx`: replaced its own one-off back button (different icon size, different margins) with the shared `AppBackButton` (`components/OriginBackButton.tsx`) used by every other back-navigable screen. This also let a magic `marginTop: 30` on the icon row be removed — it existed only to compensate for the bespoke button's different spacing; with the shared button the icon row needs no extra margin, matching the pattern already used on the auth screens (forgot-password, verify-code).
  - `app/(app)/home.tsx`: the "Recent activity" list had its own `gap: spacing.xs` container style stacked on top of `NotificationRow`'s built-in `marginBottom`, so the same row rendered with ~12px between items on Home but only 8px on the Notifications tab (which has no such extra gap). Removed the redundant gap. Also rounded `phaseChips`' `gap: 5` to the grid-aligned `spacing.xs` (4).
  - Also folded in Help & Support's title-next-to-icon layout change (asked separately, same screen).
- Explicitly did not touch: the differing gaps between project cards (16px) vs. invoice rows (12px) vs. notification rows (8px) — different content density, judged intentional, not a bug. Account's `paddingBottom: 64 + spacing.md` override — documented in this file's own prior history as a deliberate fix for the version footer getting clipped by the tab bar; no simulator available this session to safely verify a change there. A handful of `marginTop: 2` optical nudges under labels — a consistent, repeated micro-pattern across many files already, not an accident.
- Verified with `npx tsc --noEmit` from `mobile/`. Not run on a device/simulator this session.
- Committed `mobile/app/(app)/home.tsx` and `mobile/app/(app)/settings/help-support.tsx` together. `home.tsx` also carried unrelated pending translation-string work that was already uncommitted in that file before this pass — flagged to the user, who confirmed it was fine to commit together.
