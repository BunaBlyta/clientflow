# Mobile: buffered theme swap's re-render before starting the fade-back-in

- Continuation of the theme toggle work: after switching to the content-dim technique (dim opacity → swap theme → fade back in, all native-driven), user reported "now it kinda lags when toggle is in the middle."
- Root cause: `lib/theme.ts`'s `ThemeProvider.setMode` called `setCurrentMode(nextMode)` and then immediately started the fade-back-in `Animated.timing` in the same synchronous tick. `setCurrentMode` swapping `mode` re-renders every `useTheme()` consumer app-wide — and because `app/(app)/_layout.tsx`'s `Tabs` navigator is configured with `lazy: false` and `detachInactiveScreens={false}`, all 5 tab screens (Home, Projects, Invoices, Notifications, Account) stay mounted simultaneously and all re-render on every theme change, not just the one currently visible. That's a genuinely heavy synchronous JS-thread commit, and starting the fade-back-in animation in the same tick raced it — the hitch is that commit, landing right at the dim trough ("in the middle").
- Fix: wrapped the fade-back-in's `.start()` call in two nested `requestAnimationFrame` callbacks after `setCurrentMode`, so the heavy commit gets roughly two frames of headroom to actually finish before the next native animation command is issued, instead of both happening in the same tick.
- Important caveat, called out to the user in `CURRENT-mobile.md`: this changes *timing*, not the underlying *cost* — all 5 tabs still fully re-render on every theme switch either way. If this doesn't fully resolve the lag, the next real lever is reducing what re-renders (e.g. enabling `detachInactiveScreens` so only the visible tab is mounted, or wrapping each tab screen in `React.memo`) — a bigger change to the tab navigator's behavior that wasn't attempted here since it risks affecting things well beyond the theme toggle (tab switch animations, mount/unmount behavior) without a way to verify visually.
- Verified with `npx tsc --noEmit` from `mobile/`. Not verified on a device this session.
- Committed `mobile/lib/theme.ts` alone.
